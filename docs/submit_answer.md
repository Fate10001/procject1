# 可直接提交的第 04 题答案

我构建了一个多 Agent 协同的 AI 自动化任务处理平台，用于解决复杂业务任务在人工处理过程中拆解成本高、执行效率低、输出质量不稳定的问题。系统采用前后端分离架构，后端基于 FastAPI 实现 Agent 工作流调度，前端基于 React + Vite 实现任务输入、流程展示、结果查看和运行状态可视化。

该系统包含 Planner Agent、Researcher Agent、Executor Agent、Reviewer Agent 和 Reporter Agent。用户输入自然语言任务后，Planner Agent 会先识别任务类型并拆解执行步骤；Researcher Agent 负责提取关键需求、背景信息和限制条件；Executor Agent 根据任务计划生成具体方案或结构化内容；Reviewer Agent 对输出结果进行质量审核、完整性检查和风险识别；Reporter Agent 最终整合所有中间结果，生成可提交的结构化报告。

项目实现了任务理解、任务拆解、多 Agent 协作、工具化执行、结果校验、日志追踪和前端可视化等核心能力。每次任务执行都会生成唯一 task_id，并将各 Agent 的输入、输出、状态、耗时等信息记录为 JSONL 日志，便于后续分析、审计和效果证明。

该项目可用于 AI 客服、内容运营、数据整理、项目规划、内部知识库问答等场景。相比人工处理复杂任务，该系统可将原本 10-20 分钟的处理流程压缩到 1-3 分钟，整体效率提升约 80%，同时通过 Reviewer Agent 降低输出遗漏和逻辑错误，提高结果一致性与可复用性。
